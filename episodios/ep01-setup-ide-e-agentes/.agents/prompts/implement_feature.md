# Workflow: Implementar Nova Regra com IA

Antes de pedir código para a IA:
1. Leia `AGENTS.md` e `.agents/rules/domain_rules.md`.
2. Defina entradas, saídas e casos de erro esperados antes da implementação.
3. Após gerar o código, execute `npm test` e `npm run verify` — só considere concluído se ambos passarem.
